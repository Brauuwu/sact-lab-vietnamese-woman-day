# SACT LAB - Vietnamese Woman Day

Trang web lời chúc mừng Ngày Phụ nữ Việt Nam 20/10, được xây dựng bằng HTML, CSS và JavaScript thuần.

## Chạy trang web

Mở `index.html` trong trình duyệt. Nếu trình duyệt chặn tự phát âm thanh, nhấn nút loa để bật nhạc nền.

## Nội dung

- `img/1.png`: ảnh mở đầu
- `img/2.png` đến `img/13.png`: các lời chúc trong slideshow
- `music/st.mp3`: nhạc nền
- `.github/workflows/validate.yml`: kiểm tra cú pháp JavaScript và các asset khi push
